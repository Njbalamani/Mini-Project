How to connect a real provider

  1. Set NEXAMIND_AI_PROVIDER to openai or gemini.
  2. Add your NEXAMIND_AI_API_KEY to the environment.
  3. Optionally set NEXAMIND_AI_MODEL.
  4. Restart the server. NexaMind reads keys only from the server environment — never from the browser.
